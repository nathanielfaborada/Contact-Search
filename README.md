# Contact Search

A desktop application that searches for the closest matching contact number using the **Edit Distance (Levenshtein Distance)** algorithm. Each time you enter a number, it filters and finds the contact whose number is closest to what you typed.

## How It Works

- Enter a contact number in the search field
- The app computes the edit distance between your input and all stored contacts
- It returns the closest matching contact(s)
- Time complexity: **O(m × n)**, where `m` and `n` are the lengths of the two numbers being compared

## Technologies Used

- Python
- Tkinter (GUI)
